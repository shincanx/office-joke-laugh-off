Entry for the [make.fun bounty "One-Line Office Joke Laugh-Off"](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73): a program that writes one original single-line joke about office life (at most 200 characters) to `/output/entry.txt`.

## The joke

> I asked for a raise and got a standing desk — now I stand corrected, and underpaid.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no input. The program writes exactly the line above.
